4) Coding Standards
* TypeScript strict everywhere; no any. Zod for runtime validation at API boundaries.
* React: functional components, hooks, suspense-ready patterns, TanStack Query for data.
* UI: shadcn/ui + Tailwind; accessible by default (labels, alt, focus states, ARIA).
* State: remote state via Query; local UI state via React useState/useReducer.
* No magic strings → centralize constants in shared/.
* Drizzle for schema + queries; use parameterized queries only.
* Error handling: never swallow errors; return typed errors via RFC7807-like shape {type, title, status, detail}.
* Security: sanitize user input; protect against SQLi/XSS/CSRF; rate-limit sensitive routes; secure cookies HttpOnly, SameSite=lax|strict.

F) Notification Pattern (Interest → Chat)
1. POST /api/trip-interest creates or upserts an interest record.
2. Server emits notification to trip owner; if accepted, server creates chatThreads + threadUsers entries.
3. Client receives notification → deep-link to /chat/{threadId}; chat locked until owner accepts.

Title: Add multi-provider authentication (Email Magic Link, Google, Microsoft, Apple, Phone OTP) to Express + React app
Stack assumptions:
Backend: Express.js (TypeScript preferred), DB via Prisma (SQLite/Postgres ok)
Frontend: React (Vite/CRA)
Sessions: JWT access + refresh tokens in httpOnly, Secure cookies
Auth: Passport.js (Google, Microsoft, Apple), Nodemailer (email magic link), Twilio (phone OTP)

3) Prisma schema additions
Create/update prisma/schema.prisma:
model User {
  id           String   @id @default(cuid())
  email        String?  @unique
  phone        String?  @unique
  name         String?
  image        String?
  provider     String?   // 'google' | 'microsoft' | 'apple' | 'email' | 'phone'
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt
  sessions     Session[]
}

model Session {
  id           String   @id @default(cuid())
  userId       String
  user         User     @relation(fields: [userId], references: [id])
  refreshToken String   @unique
  expiresAt    DateTime
  createdAt    DateTime @default(now())
}

model EmailToken {
  id         String   @id @default(cuid())
  email      String
  tokenHash  String
  expiresAt  DateTime
  used       Boolean  @default(false)

  @@index([email])
}

model PhoneOtp {
  id         String   @id @default(cuid())
  phone      String   @unique
  codeHash   String
  attempts   Int      @default(0)
  expiresAt  DateTime
  createdAt  DateTime @default(now())
}

npx prisma migrate dev --name auth_init

5) JWT helpers (access + refresh, httpOnly cookies)
src/server/auth/jwt.ts:

setAuthCookies(res, {access, refresh}) with httpOnly, secure, sameSite:'lax', domain from env
clearAuthCookies(res)
Add authGuard middleware for protected POST endpoints (reads stay public).
6) Passport strategies (OAuth)
src/server/auth/passport.ts:

MicrosoftStrategy (passport-microsoft or passport-azure-ad-oauth2)
AppleStrategy (passport-apple; Services ID web flow)
On success:
find/create user by provider email
issue JWTs & set cookies
redirect to ${APP_URL}/auth/callback?ok=1
Routes to add:
GET /api/auth/google

GET /api/auth/microsoft

GET /api/auth/apple
POST/GET /api/auth/apple/callback   # per library
7) Email Magic Link
src/server/auth/email.ts:
POST /api/auth/email/start with { email }
rate-limit, create EmailToken with random token (nanoid), store hashed (bcrypt), set 10-min expiry
send email via Nodemailer: link https://theceylonx.com/auth/magic?token=...&email=...
GET /api/auth/email/verify with token,email
validate (hash compare), mark used, find/create user, issue JWT cookies, redirect to ${APP_URL}/auth/callback?ok=1
8) Phone OTP (Twilio)
src/server/auth/phone.ts:
POST /api/auth/phone/send with { phone }
normalize E.164, rate-limit, create/update PhoneOtp with hashed code (6 digits), TTL 5 min
send via Twilio (Verify or Messaging Service)
POST /api/auth/phone/verify with { phone, code }
validate/compare hash, enforce attempts limit, create/find user, issue JWT cookies, delete OTP row
9) Session routes
src/server/auth/routes.ts:

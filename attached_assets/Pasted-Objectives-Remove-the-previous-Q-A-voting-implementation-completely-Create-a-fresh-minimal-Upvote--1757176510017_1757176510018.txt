1) Data Model (Drizzle/SQL)
Tables
-- Questions (add cached score column)
ALTER TABLE questions
  ADD COLUMN IF NOT EXISTS score INT NOT NULL DEFAULT 0;

-- Answers (add cached score column)
ALTER TABLE answers
  ADD COLUMN IF NOT EXISTS score INT NOT NULL DEFAULT 0;

-- Upvotes: presence = upvoted, absence = not upvoted
CREATE TABLE IF NOT EXISTS question_upvotes (
  id SERIAL PRIMARY KEY,
  question_id UUID NOT NULL REFERENCES questions(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (question_id, user_id)
);

CREATE INDEX IF NOT EXISTS idx_question_upvotes_q ON question_upvotes(question_id);

CREATE TABLE IF NOT EXISTS answer_upvotes (
  id SERIAL PRIMARY KEY,
  answer_id UUID NOT NULL REFERENCES answers(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (answer_id, user_id)
);

CREATE INDEX IF NOT EXISTS idx_answer_upvotes_a ON answer_upvotes(answer_id);
Why presence-only? Simple toggle, fast count (COUNT(*)). We also maintain a cached score on parent rows for list performance.
2) API Contracts (GraphQL preferred)
type Question {
  id: ID!
  score: Int!        # cached
  viewerUpvoted: Boolean!   # computed for current user
}

type Answer {
  id: ID!
  score: Int!
  viewerUpvoted: Boolean!
}

type Mutation {
  toggleQuestionUpvote(questionId: ID!): Question!  # flips state; returns updated score + viewerUpvoted
  toggleAnswerUpvote(answerId: ID!): Answer!
}

type Subscription {
  questionScoreUpdated(id: ID!): Question!  # emits { id, score }
  answerScoreUpdated(id: ID!): Answer!
}

POST /api/answers/:id/upvote/toggle
SSE channels: /api/stream/questions/:id/score, /api/stream/answers/:id/score
3) Server Logic (Resolvers/Services)
Toggle (transactional):
Require auth. Get userId from session/JWT; ignore client-sent user.
Start TX:
If upvote exists → DELETE from *_upvotes; delta = -1
Else → INSERT; delta = +1
Update cached score = score + delta on questions or answers.
Publish realtime event with the updated score.
Return { id, score, viewerUpvoted }.
Queries:
viewerUpvoted = EXISTS(SELECT 1 FROM *_upvotes WHERE item_id = ? AND user_id = currentUser)
Rate limits:
Basic throttling (e.g., 10 toggles/10s per user per item).
Pub/Sub:
Use existing WS/GraphQL-Subscriptions (or SSE). Topic keys:
question_score_updated:${id}
answer_score_updated:${id}
4) Client (Next.js + Zustand)
UI rules:
One button per item: ⬆️ Upvote (toggle).
States:
Active (filled icon, bold label) → user has upvoted.
Inactive (outline icon) → user hasn’t.
Optimistic update:
If inactive → set viewerUpvoted=true, score+1.
If active → set viewerUpvoted=false, score-1.
On error → revert + toast.

Example button (shadcn/ui + framer-motion)
"use client";
import { Button } from "@/components/ui/button";
import { motion } from "framer-motion";
import { useState } from "react";

type Props = {
  itemId: string;
  kind: "question" | "answer";
  initialScore: number;
  initialViewerUpvoted: boolean;
  onToggle: (kind: "question"|"answer", id: string) => Promise<{score:number; viewerUpvoted:boolean}>;
  subscribe: (kind: "question"|"answer", id: string, cb: (score:number)=>void) => void;
};

export default function UpvoteButton({ itemId, kind, initialScore, initialViewerUpvoted, onToggle, subscribe }: Props) {
  const [score, setScore] = useState(initialScore);
  const [upvoted, setUpvoted] = useState(initialViewerUpvoted);
  const [saving, setSaving] = useState(false);

  // subscribe once
  useState(() => {
    subscribe(kind, itemId, (s) => setScore(s));
  });

  const handleClick = async () => {
    if (saving) return;
    setSaving(true);
    const prev = { upvoted, score };
    // optimistic
    const nextUp = !upvoted;
    setUpvoted(nextUp);
    setScore(score + (nextUp ? 1 : -1));
    try {
      const res = await onToggle(kind, itemId);
      setUpvoted(res.viewerUpvoted);
      setScore(res.score);
    } catch {
      setUpvoted(prev.upvoted);
      setScore(prev.score);
      // toast error
    } finally {
      setSaving(false);
    }
  };

  return (
    <motion.div whileTap={{ scale: 0.95 }}>
      <Button variant={upvoted ? "default" : "outline"} size="sm" onClick={handleClick} disabled={saving} aria-pressed={upvoted} aria-label="Upvote">
        ⬆️ {upvoted ? "Upvoted" : "Upvote"} • {score}
      </Button>
    </motion.div>
  );
}
